# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within ForgeQueue, please send an email to `security@forgequeue.local` or open a confidential advisory. Please do not disclose vulnerabilities publicly until a fix has been prepared and released.

Please include:
- A detailed description of the vulnerability.
- Steps or code to reproduce the issue.
- Potential impact and affected components (API, Worker, Container Isolation).
